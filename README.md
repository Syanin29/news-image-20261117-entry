## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies the pre-rendered `entry.png` (rendered at build time by `render.py` from verified 17 November 2026 facts) to the output directory, byte for byte. Standard library only, no network, deterministic.
